# 绘图层 DrawingLayer（画规）

## 结构
- canvas 覆盖 `left: w-stage` 到右缘，top 0，高 = 整块画板高（随内容滚动）
- 每次重绘：先清屏 → 逐条绘制线段 → 端点徽标 → 中点手柄

## 样式
- 线宽 2.5px（设置里可调 细/中/粗 → 1.8/2.5/3.5）
- 端点徽标：白底实心圆 r=17px，环 2.5px 用线色，中心数字 18px/700 线色，带 `0 1px 3px rgba(0,0,0,.18)` 阴影
- 中点手柄：9×9 菱形，填充线色、1.5px 白边
- 8 色调色板：红 #FE0000 / 蓝 #1E3FE0 / 紫 #8B2FD0 / 橙 #F2701D / 绿 #5CB85C / 棕 #A0522D / 青 #17C3C0 / 黑 #111111

## 交互
- pointerdown 在号码格 → 吸附到该格中心；移动实时预览；pointerup 落点吸附到另一格 → 提交线段
- 起止点相同或位移 <8px（判定为单击）→ 不生成线，改为切换该号码的「号码样式」标记
- 拖线身（距线段 <14px）→ 整条线平移；拖端点徽标 → 只移动该端点（折弯/拉直）；两者松开时都按行列吸附到最近号码格
- 位移始终以拖动起点为基准计算，避免逐帧累积
- 锁定后不响应指针
- 撤销/恢复：线段栈；清除：全清（可撤销）
- 端点吸附列：万/千/百/十/个 共 5 列
