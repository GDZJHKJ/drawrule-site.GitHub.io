# 设置页 SettingsSheet

## 结构
- fixed 全屏，bg #f6f6f6，顶部返回栏（白，56px，居中标题「设置」）
- 白色卡片分组，圆角 6px，左右 14px，组间距 10px，组内 padding 14px
- 分组：
  1. 期数：4 个 pill（20/40/60/80）
  2. 字体大小：标准/大号/超大号
  3. 自定义皮肤：4 张缩略卡片（CSS 迷你走势图 48×60）+ 选中红勾角标
  4. 画板缩放比例：50/60/70/80/90/100%
  5. 四期分割线：常用分割 / 本年分割 / 全部分割（圆形单选 + 对勾）
  6. 号码样式：文本 / 空心方 / 空心圆 / 实心方 / 实心圆 —— **不是全表换形**，而是「点击号码时打上的标记形状」
  7. ~~辅助开关：数字选择器~~（已移除，交互改为点击号码直接打标）

## 样式
- 标题 0.14rem #333 700；选项文字 0.13rem #333
- 选中：浅红底 #FDECEC + 红字；缩放比例选中为实心红底白字
- 卡片阴影：0 1px 2px rgba(0,0,0,.04)

## 交互
- 选项即时生效并写 localStorage
- 下拉/收起使用 240ms cubic-bezier(.32,.72,0,1)
