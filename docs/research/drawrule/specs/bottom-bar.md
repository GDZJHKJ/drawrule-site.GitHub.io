# 底部悬浮控件 BottomBar

## 结构
- fixed bottom 15px，左右 11px
- 左：colorBtn 42px 圆（bg bar）+ 内 31px 当前色圆
  - 展开态：向上 8 色竖排（间距 41.6px，圆 31px，当前色打白勾）+ 右侧 3 个 42px 工具圆（直线/折线/自由），激活态红色
- 中：lockBtn 42px 圆（bg bar），锁图标 25px
- 右：textSet 胶囊 125×52（右侧直角，「设置」字 0.14rem 白）+ icon 42px 圆（画笔设置图标）

## 交互
- 点色块 → 换当前色并收起
- 点工具 → 切换绘制模式（直线/折线/自由）
- 点锁 → 锁定/解锁；锁定后 lock 图标变实心亮色
- 点设置胶囊或右侧圆 → 打开设置页
