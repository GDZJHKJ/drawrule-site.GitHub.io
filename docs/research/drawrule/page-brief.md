# 页面结构拆解 — 排列五「画规」走势画板

- 源站：`https://static.shichaisz.com/xcxweb/index.html#/drawRule3/2?from=seo`
- 页面标题：`画规`（品牌 `拾柴排列五`，克隆时已替换）
- 形态：移动端 H5 单页应用（Vue SPA + hash 路由），无桌面适配 —— 原站在 1440px 下按 `26.667vw` 等比放大到全宽，字号被放到 46px 级，属于「只按手机设计」的实现。
- 勘查时间：2026-11-16

## 区块清单（自上而下）

1. **顶部工具条**（`position:fixed`，高 50px，背景 `#93C385`）
   7 个条目：关闭 ｜ 分割线 ｜ 撤销、恢复、清除、分享、保存、设置。每项 = 图标（17px，iconfont）+ 12.48px 白字标签，宽 54px。
2. **走势画板**（高 = 视口 − 50px，内部纵向可滚动，默认滚到底部）
   - 四层背景：期号列（绿 `#93C385`）、和值列（`#EFF9CA`）、万千百十列（白）、个位列（`#EFF9CA`）
   - 行：每行 50px，内容 = 期号 + 日期（白色 16.64/10.4px）｜ 前四位和值（16.64px `#A3C199`）｜ 5 个开奖号码数字（31.2px 粗体，前四位 `#93C385`，个位 `#A3C199`）
   - 网格：每行底边 1px `#CEE2CC`；每 4 行一条 2.1px `#77A067`（「四期分割线」）；纵向 1px 线分隔千万百十列，2.1px 线分隔期号/和值/号码区/个位区
   - 空行：数据之后保留 6 行空白（下一期、未开奖）
3. **绘图层**（覆盖号码区，从期号列右侧到屏幕右缘）
   直线工具：从一个号码格拖到另一个号码格 → 直线 + 两端「白底彩圈 + 彩色数字」标记 + 中点菱形手柄。
4. **底部悬浮控件**（距底 15px）
   - 左：颜色按钮（42px 深灰圆 + 31px 当前色圆点），点开向左上展开 8 色竖排色板 + 3 个工具按钮
   - 中：锁定按钮（42px 深灰圆，锁图标），锁上后不可绘制
   - 右：「设置」胶囊（125×52，左侧大圆角）+ 42px 圆形图标按钮
5. **首次进入引导层**（全屏 45% 黑遮罩）
   竖排文字「期号列表可上下移动」+ 上下两个白色箭头 + 一只手型图标 + 「知道了」描边按钮；点击后写入本地标记，不再出现。
6. **设置页**（点击「设置」从下方推入的全屏白卡列表）
   分组：期数（20/40/60/80）、字体大小（标准/大号/超大号）、自定义皮肤（经典/护眼/夜间/怀旧）、画板缩放比例（50%–100%）、四期分割线（常用分割/本年分割/全部分割）、号码样式（空心方/空心圆/实心方/实心圆）、辅助开关（数字选择器）。

## 页面级行为

- 画板纵向滚动；进入时自动滚到最新一期（底部）。
- 期号列被一层 mask 覆盖（`stagesMask`），用于承接纵向拖拽 → 「期号列表可上下移动」引导即指此。
- 绘制内容随画板一起滚动（绘图层尺寸 = 整块画板高度，非视口高度）。
- 无页面级动效；设置页为推入式浮层。
